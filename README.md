# Mario Kart 64 VR

Mario Kart 64 in VR, built on SpaghettiKart.

Install it through the [Multiverse VR Hub](https://github.com/RaYRoD-TV/MVRH). One exe.. it grabs the official SpaghettiKart release, applies my VR patch & keeps it updated. There's a standalone Quest build too. Bring your own ROM.

No PC or Quest builds here anymore, the hub is the one spot for all of it, source included.
